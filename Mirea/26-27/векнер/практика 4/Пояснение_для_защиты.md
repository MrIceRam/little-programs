# ТСАУ ПР 4, вариант 13: как объяснить решение

## Часть 4.1. Уравнение 3y‴ + 6y″ + 9y′ + 3y = u″ + 3u′ + 6u

**1. Передаточная функция.** Применяем преобразование Лапласа при нулевых начальных условиях:
**W(s) = (s² + 3s + 6) / (3s³ + 6s² + 9s + 3) = (⅓s² + s + 2) / (s³ + 2s² + 3s + 1)**.
- Порядок 3, числитель 2-го порядка, поэтому D = 0.
- W(0) = 6/3 = 2, это и есть установившееся значение h(∞).

**Матрицы «прямо из уравнения» (β-метод).** Вводим x₁ = y, x₂ = ẋ₁ − β₁u, x₃ = ẋ₂ − β₂u.
- Формула: βₖ = bₖ* − Σ aⱼ*·βₖ₋ⱼ.
- Получается β = (0; ⅓; ⅓; ⅓).
- A — сопровождающая матрица (последняя строка −1, −3, −2), B = (⅓; ⅓; ⅓)ᵀ, C = [1 0 0].

**2. Фробениусова строчно-управляемая форма.** Вводим вспомогательную z: z‴ + 2z″ + 3z′ + z = u, тогда y = ⅓z″ + z′ + 2z.
- Состояние: x = (z, ż, z̈).
- A_Ф — та же сопровождающая матрица, B_Ф = (0; 0; 1)ᵀ: вход входит только в последнее уравнение.
- C_Ф = [2 1 ⅓] — коэффициенты числителя.

**Жорданова форма.**
- Корни: λ₁ = −0,4302, λ₂,₃ = −0,7849 ± j1,3071. Все слева, значит система устойчива.
- Вычеты: r₁ = 0,8894, r₂,₃ = −0,278 ∓ j0,1069.
- Диагональная (комплексная) форма: A_J = diag(λᵢ), B = (1; 1; 1)ᵀ, C = (r₁, r₂, r₃).
- Для моделирования пару заменили вещественной клеткой [[σ, ω], [−ω, σ]]. Тогда B = (1; 0; 1)ᵀ, C = (r₁; −2β; 2α) = (0,8894; 0,2138; −0,5560).
- Переход фробениусова → жорданова форма делается матрицей Вандермонда, её столбцы (1; λᵢ; λᵢ²).

**3. Сравнение передаточных функций.** У всех форм W(s) совпадает с исходной. Причина: формы связаны преобразованием подобия x = T·x̃, а C(sI − A)⁻¹B к нему инвариантна, потому что T и T⁻¹ сокращаются.

**4. Сигнальные графы.** У графа Фробениуса все три контура (−2/s, −3/s², −1/s³) касаются узла ẋ₃.
- Формула Мейсона: Δ = 1 + 2/s + 3/s² + 1/s³.
- Пути: 2/s³, 1/s², ⅓·1/s. Отсюда сразу получается W(s). Это хороший ответ на вопрос «как проверить граф».

## Часть 4.2. Комбинация FFG: F — вариант 13, G — вариант 14

**Почему FFG и почему G из варианта 14.** В таблице 5 под столбцом 13 написано «13-14» и «FFG». Первая подсистема F — матрицы варианта 13, G — матрицы варианта 14. Прямой тракт F·F, обратная связь G (отрицательная).

**1. Внешние модели подсистем.**
- W_F = (3s − 2)/(s² − 4s + 1), собственные числа 2 ± √3.
- W_G = (s − 1)/(s² − 5s + 5), собственные числа (5 ± √5)/2.
- Обе подсистемы неустойчивы.

**2. Замкнутая система.** Φ = W_F²/(1 + W_F²·W_G).
- С исходными A знаменатель s⁶ − 13s⁵ + 63s⁴ − 129s³ + …
- Знаки чередуются, все полюсы справа, система неустойчива.
- **Смена знаков:** поменяли знаки у всех элементов обеих матриц A (A → −A). Собственные числа подсистем зеркально переходят влево.
- Результат: Φ(s) = (9s⁴ + 57s³ + 109s² + 80s + 20) / (s⁶ + 13s⁵ + 63s⁴ + 147s³ + 152s² + 61s + 9).
- Все определители Гурвица > 0 (13; 672; 73889; …).
- Полюсы: −0,318 ± j0,137; −1,305; −2,665 ± j1,716; −5,729.
- Если спросят «а можно меньше смен знаков?» — да, перебор показал 14 устойчивых комбинаций. Выбран самый наглядный вариант A → −A.
- Проверка внутренней моделью: собрали матрицу 6×6 из A_F, A_F, A_G и связей B·C. Её собственные числа равны полюсам Φ(s). Сокращений нет, порядок 6 = 2 + 2 + 2.

**3. Форма Люенбергера.** Для одномерной системы это наблюдаемая каноническая форма.
- Первый столбец A_Л равен −(13, 63, 147, 152, 61, 9), над диагональю стоят единицы.
- B_Л = (0; 9; 57; 109; 80; 20), C_Л = [1 0 0 0 0 0].
- По схеме: каждый сумматор получает x_{i+1}, −aᵢ·y и bᵢ·u.

**4. Форма Коши–Фробениуса.** Это управляемая форма.
- Цепочка интеграторов, в последней строке A_К стоят −(9, 61, 152, 147, 63, 13).
- B_К = (0; …; 1), C_К = [20 80 109 57 9 0].
- Она дуальна форме Люенбергера: A_К = A_Лᵀ с точностью до перенумерации координат.

## SimInTech

**Где лежит.** Проекты `SimInTech/ПР4_1.xprt` и `SimInTech/ПР4_2.xprt`, это XML-формат SimInTech, открывается двойным щелчком.

**Что внутри.** В каждом проекте одна ступенька на три схемы:
- блок «Передаточная функция общего вида»;
- две канонические формы, собранные из интеграторов и сумматоров с весовыми коэффициентами (веса подписаны на входах сумматоров);
- временной график и блок «В файл». Он пишет `pr4_1.dat` и `pr4_2.dat` со столбцами t, u, W, форма 1, форма 2.

**Как запустить.** Открыть проект и нажать «Пуск». Расчёт RK45, шаг ≤ 0,01 с, время 20 и 40 с.

**Результат.**
- Все три кривые совпадают.
- Отклонение от точной переходной функции (через вычеты W(s)/s): 5,6·10⁻¹⁴ в части 4.1 и 1,3·10⁻¹¹ в части 4.2.
- h(∞) равно 2 и 20/9 ≈ 2,2222.

**Как собраны схемы.** Генерирует скрипт `SimInTech/build_pr4.py` (шаблоны блоков в `SimInTech/templates`). Если попросят собрать вручную, понадобятся блоки:
- «Ступенька» (Источники);
- «Сумматор» с вектором весов и «Интегратор» (Операторы / Динамические);
- «Передаточная функция общего вида» (Динамические);
- «Временной график» и «В файл» (Вывод данных).
