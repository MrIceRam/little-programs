# ТСАУ ЛР 4 — вариант 13: как объяснить решение

**Исходные данные.** k = 8, T₁ = 0,3 с, T₂ = 0,15 с, T₃ = 0,12 с. Три инерционных звена подряд, k стоит в первом звене, обратная связь отрицательная единичная.

**1. Передаточные функции.**
- Разомкнутая: W(s) = k / ((0,3s+1)(0,15s+1)(0,12s+1)) = k / (0,0054s³ + 0,099s² + 0,57s + 1).
- Замкнутая: Φ(s) = W/(1+W) = k / (0,0054s³ + 0,099s² + 0,57s + 1 + k).

**2. Гурвиц.** a₀ = 0,0054, a₁ = 0,099, a₂ = 0,57, a₃ = 1 + k.
- Для 3-го порядка всё решает Δ₂ = a₁a₂ − a₀a₃ = 0,05643 − 0,0054(1+k) > 0.
- Δ₂ = 0 → 1 + k = 10,45 → **k_пр = 9,45**.
- Проверка общей формулой: k_пр = (T₁+T₂+T₃)(1/T₁+1/T₂+1/T₃) − 1 = 0,57 · 18,33 − 1 = 9,45.
- На границе корни ±jω, ω = √(a₂/a₀) = √(0,57/0,0054) = **10,27 с⁻¹** (период 0,61 с).

**3. Переходные характеристики (k = 8; 9,45; 11).**
- k = 8: затухает, h(∞) = 8/9 = 0,889, перерегулирование 78,8 %, tп ≈ 8,8 с. Корни −17,69 и −0,321 ± j9,701 (очень близко к мнимой оси, поэтому так долго качается).
- k = 9,45: незатухающие колебания с периодом 0,61 с.
- k = 11: колебания растут (корни 0,309 ± j10,82 справа).

**4. Найквист.** Разомкнутая система устойчива (полюсы −3,33; −6,67; −8,33), значит замкнутая устойчива, если годограф не охватывает (−1; j0).
- Ось годограф пересекает при ω = 10,27, в точке W = −k/9,45.
- k = 8 → −0,847 (не охватывает, устойчива); k = 9,45 → −1 (граница); k = 11 → −1,164 (охватывает, неустойчива).

**5. Запасы при k = 8.**
- По амплитуде: 1/0,847 = 1,181 раза = **1,45 дБ** (это ровно k_пр/k = 9,45/8).
- По фазе: годограф пересекает единичную окружность при ωс = 9,51 с⁻¹, фаза −174,5° → **5,5°**.
- По Боде то же самое: L(ωπ) = −1,45 дБ при φ = −180°; φ(ωс) = −174,5° при L = 0. ωс < ωπ, значит устойчива.

**6. Если спросят «почему запасы такие маленькие».** k = 8 всего в 1,18 раза меньше предельного. Для нормального запаса 6 дБ нужно k ≈ 4,7.
