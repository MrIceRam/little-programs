# ТСАУ ЛР 3 — вариант 13: как объяснить решение

**Исходные данные (таблица 3, вариант 13).** A = [−1 1 3; 0 2 2; 1 −1 1], B = [1 1 0]ᵀ, C = [3 1 1].

**1. Исходная система неустойчива.** det(sI − A) = s³ − 2s² − 2s + 8. Коэффициенты разных знаков, поэтому не выполнено даже необходимое условие устойчивости. Корни: −1,751 и 1,876 ± j1,025. Два корня справа, процесс колебательно расходится (h(3) ≈ −323).

**2. Как сделал устойчивой.** Перебрал все смены знаков. Смена одного элемента не помогает ни для какого элемента. Из пар подходит только одна: a₂₂ (2 → −2) и a₁₃ (3 → −3).
- a₂₂ = +2 — это положительная обратная связь x₂ на себя («разгон»). После смены знака она становится отрицательной.
- Контур x₁ → x₃ → x₁ имел коэффициент a₁₃·a₃₁ = +3. После смены знака a₁₃ он стал −3, то есть отрицательной связью.
- Получилось s³ + 2s² + 4s + 4. По Гурвицу все aᵢ > 0 и Δ₂ = a₁a₂ − a₀a₃ = 8 − 4 = 4 > 0, значит система устойчива.

**3. Структурная схема.** Три интегратора, перед каждым сумматор. На вход сумматора i приходят xⱼ через усилители aᵢⱼ и u через bᵢ. Выход: y = 3x₁ + x₂ + x₃.

**4. ПФ по схеме (правило Мейсона).**
- Контуры: −1/s, −2/s, 1/s (собственные); −3/s² (x₁↔x₃), −2/s² (x₂↔x₃); 2/s³ (x₁→x₃→x₂→x₁).
- Δ = 1 + 2/s + 4/s² + 4/s³.
- Прямых путей восемь (таблица 2 в отчёте), их сумма ΣPₖΔₖ = (4s² + 6s + 12)/s³.
- Итог: **W(s) = (4s² + 6s + 12)/(s³ + 2s² + 4s + 4)**.

**5. ПФ по матрицам.** W = C·adj(sI − A′)·B / det(sI − A′), где adj(sI − A′)B = [s² + 2s + 2; s² + 4; 2]. Получаем 3(s² + 2s + 2) + (s² + 4) + 2 = 4s² + 6s + 12. Результат тот же.

**6. SimInTech.** Блок «Построение передаточных функций» (двойной щелчок после расчёта) выдаёт Ns = [12, 6, 4] и Ls = [4, 4, 2, 1]. Коэффициенты идут от младшей степени к старшей, то есть это та же W(s).

**7. Переходная характеристика.** Кривые по схеме, по W(s) и по матрицам совпадают. h(∞) = W(0) = 12/4 = 3, перерегулирование 8,7 %, время переходного процесса около 5,2 с. Колебания идут из-за полюсов −0,352 ± j1,721.

## Как запустить в SimInTech
1. Откройте `SimInTech/ЛР3_устойчивая_система.prt` (или `ЛР3_исходная_система.prt`).
2. Нажмите «Пуск» (зелёный треугольник). Окно графика h(t) откроется само.
3. Чтобы увидеть W(s), посчитанную SimInTech по схеме, дважды щёлкните блок «W(s) по схеме» после расчёта.
4. Матрицы в блоке «Переменные состояния» записаны по столбцам: так их хранит SimInTech.
